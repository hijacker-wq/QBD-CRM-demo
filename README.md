# QBD CRM demo

Live demo: https://hijacker-wq.github.io/QBD-CRM-demo/

A static demo of a clinic CRM (patients, calendar, reception queue, booking requests, medical sheets).
All records are synthetic. There is no server: a small script in the page (`app/demo-api.js`) answers the
CRM's requests from `app/demo-data.json`. Changes you make stay in your browser tab and reset on reload.
